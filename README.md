# Hero Slider

A main hero slider for your site: attractive slides, visual effects, and per-slide buttons, with simple controls from the admin panel.

Use it to highlight offers, products, or key messages at the top of the page — clean on both mobile and desktop.

## Install
1. Upload the plugin folder to `wp-content/plugins/`
2. Activate it from the dashboard
3. Create and arrange slides in the plugin settings
4. Place the shortcode where you need the slider
